- 작업 규칙과 진입점: [CLAUDE.md](CLAUDE.md)
- 요구사항: [docs/product.md](docs/product.md)
- 데이터 출처: [docs/data-sources.md](docs/data-sources.md)
- 현재 상태: [docs/tracking/status.md](docs/tracking/status.md)
