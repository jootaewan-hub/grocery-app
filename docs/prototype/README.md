# v0 시안 (2026-10-16, claude.ai 아티팩트)

`v0-artifact.html`은 claude.ai 아티팩트 런타임(`window.claude.use(...)`)에서만 동작한다. 그대로 실행하거나 옮겨 쓰지 않는다. 기능 목록과 검증 아이디어를 참고하는 용도다.

## 왜 실패했나

- 화면을 한 번도 렌더링해 보지 않고 게시했다. 디자인 반복이 없었다.
- 아티팩트는 외부 이미지를 막는다 → 상품 사진이 없는 쇼핑 앱이 됐다.
- 외부 API를 직접 부를 수 없어 "웹 검색(Exa) → Claude가 요약"으로 우회했다 → 품목당 오래 걸리고, 공공 시세가 비거나 옛 값(KAMIS 사과에서 3월 자료)이 잡혔다.
- 카메라·바코드 스캔, 홈 화면 설치가 안 됐다.
- 배우자 계정에도 Exa 커넥터 연결과 Claude 사용 허용이 필요했다.

## 가져갈 것

- 근거 검증: 모델이 정리한 값 가운데 출처 URL이나 숫자가 원문에 없는 것은 버리고, 버린 개수를 화면에 알린다. 정식 앱에서는 API 응답 값을 그대로 쓰므로 모델 정리 단계 자체를 최소화한다.
- 글 입력 파싱: 한 줄 한 품목, `x2`/`×2`/`2개` 개수, `600g`·`1.05kg`·`30구`·`1포기` 같은 용량 분리.
- 분류 키워드 사전(정육·수산·채소·과일·유제품·계란·가공·냉동·음료·생활용품). 한 글자 품목(배, 무, 감, 굴)은 단어 단위로만 일치시킨다.
- "찾은 기록 없음"과 "안전함"을 구분하는 문구.
- 시세 등락 색: 오르면 빨강, 내리면 파랑(국내 관례).

## 버릴 것

- 품목마다 웹 검색 4번 + 모델 요약 1번을 하는 확인 방식.
- 브라우저 저장소에 의존한 상태 관리, 문자열로 HTML을 이어 붙이는 렌더링.
