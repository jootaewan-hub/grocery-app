# 무엇을 만드는가

## 요구사항 (사용자 요청 요지, 2026-10-16)

- 품목을 글로 적거나 사진을 올리면, 앱이 그것을 보고 해당 품목의 정보를 가져온다.
- 식품이면 위반사항(회수·판매중지·행정처분)이나 변경사항(리뉴얼, 용량·원재료 변경 등)이 있는지 보여 준다.
- 여러 쇼핑 플랫폼의 가격을 보여 준다.
- 더 좋은 대안 상품이 있는지 보여 준다.
- 고기·채소·과일 등은 매일·매주 가격이 변하므로 가격 변동을 파악할 수 있게 한다.
- 깔끔한 앱 디자인. 가계부 앱의 디자인이 괜찮으면 가져온다.
- AI 느낌이 나지 않게, 편의성을 강조한다.
- 사용자는 부부 두 사람뿐이다.

## 화면 (초안 — 디자인 시안 확정 전)

1. **장보기 목록** — 분류별(정육·수산·채소·과일·유제품·계란·가공·냉동·음료·생활용품) 묶음. 한 번 눌러 산 것으로 체크. 품목 옆에 최저가, 시세 변동, 경고 배지. 상단 요약: 살 것 개수, 확인된 최저가 합계, 확인 필요 개수.
2. **담기** — 줄마다 한 품목(용량·개수 함께, 예: `비비고 왕교자 1.05kg x2`). 자주 사는 품목 빠른 담기. 사진(메모·냉장고·제품 포장·영수증)에서 품목 추출 후 확인 목록. 바코드 스캔.
3. **품목 상세** — 상품 이미지, 쇼핑몰별 가격(같은 상품/다른 용량 구분, 단위가격), 식약처 기록과 제품 변경 소식, 공공 시세(당일·전일·1주·2주·1개월·1년·평년 대비), 우리 가구가 기록한 가격 추이, 대안 상품, 출처 목록.
4. **시세** — 지켜보는 품목의 시세와 추이(매일 자동 수집), 식약처 최신 회수·판매중지 목록.
5. **기록** — 월별 장보기 지출, 분류별 합계, 날짜별 구매 내역, 누가 샀는지. 가계부 앱과 연결 여부는 확정 전.

## 사용 맥락

- 마트에서 한 손으로 쓴다: 터치 영역 44px 이상, 주요 동작은 화면 아래쪽.
- 두 사람이 같은 목록을 실시간으로 본다. 누가 담았는지, 누가 샀는지 표시한다.
- 휴대폰 홈 화면에 설치해 앱처럼 쓴다(PWA).
